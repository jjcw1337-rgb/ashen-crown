## ⚡ Performance

**Nightly perf 2026-11-01: model textures stored as lossy WebP (q0.9) instead of lossless. Download less than half the size.**
- Mac .zip **725 → 302 MiB (-58%)**, Windows zipped **704 → 281 MiB (-60%)**, Linux zipped 275 MiB; pack 682 → 255 MiB. Without the 81.5 MiB intro the Mac download is ~220 MiB.
- Cause: the 249 textures Godot extracts from the .glb files were imported **lossless** (git-ignored .import files take the importer's default), turning 0.5-3 MB JPGs into 4-9.5 MB files: 490 of the 602 MB import cache.
- Fix: `[importer_defaults] texture` in project.godot (lossy, quality 0.9, 3D detection off), plus the 5 Plague coat dyes. Checked on a fresh clone, the way CI imports.
- Look: ~41 dB against the source JPGs; screenshots before → after differ no more than two identical runs do (images: look_*_before_after.png, texture_*_src_vs_webp.png).
- Frame rate unchanged (moor High 22.9 fps, Medium 37.9, Ultra 9.2, camp 12.4). Load **~1-1.4 s faster** (moor High 5.2 → 3.8 s).
- New in the perf hook: GPU ms, GPU busy %, video memory, load time. The GPU is only 57-66% busy, so the main thread is the limit. The camp draws **152 M primitives/frame** (moor: 20 M), the next big target.
- Tests green: playtest, grass, coop_fx, title, bg (server + client), mp (host + join). Two old failures also on the untouched commit: the `Sfx` compile message at tool load, and mp_test [H4] partner pos.
