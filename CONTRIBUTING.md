# Working on Ashen Crown

## Getting set up

1. Install **Godot 4.3** (the standard build, not .NET): https://godotengine.org/download/archive/4.3-stable/
   Other versions may refuse to open the project or behave differently. Stick to 4.3.
2. Clone this repository (GitHub Desktop is the easiest way if you're new to git).
3. In Godot, click **Import**, pick `project.godot`, then press **F5** to play.

The first open takes a minute while Godot builds its cache in `.godot/` (that folder is not committed).

## How the project is laid out

There are no art, sound or model files. Everything is generated by code in `scripts/`:

| File | What it does |
|---|---|
| `game.gd` | The main loop: zones, camera, graphics presets, saving, acts/difficulty runs, co-op wiring |
| `world.gd` | Builds each zone: terrain, roads, buildings, trees, grass, spawn points |
| `hero.gd` | The player's knight: movement, combat, skills, stats, gear |
| `enemy.gd`, `projectile.gd` | Monsters, their AI and attacks |
| `data.gd` | **Most tuning lives here:** monsters, items, uniques, skills, acts |
| `items.gd` | Item generation, affixes, tooltips, enchanting |
| `ui.gd`, `hud_bar.gd` | All menus and the HUD |
| `net.gd` | LAN co-op (host-authoritative, ENet) |
| `models.gd`, `skeleton.gd`, `flora.gd`, `props.gd`, `geo.gd` | Procedural 3D models |
| `mats.gd` | Shaders for terrain, props, cloth |
| `weather.gd`, `fx.gd`, `sfx.gd` | Snow/ash, particles, sound |
| `tools/` | Headless test scripts (not shipped) |

Good first changes: tweak a monster or item in `data.gd`, press F5, see the difference.

## Publishing

Every push to the `main` branch automatically:

1. exports the browser version and a Windows build with Godot 4.3 (GitHub Actions, see `.github/workflows/deploy.yml`),
2. publishes the browser version to this repo's GitHub Pages address,
3. puts the Windows download at `<pages address>/AshenCrown-Windows.zip`.

It takes about 3–5 minutes. Watch progress in the repository's **Actions** tab; a red X means the export failed, and clicking it shows why.

To try something without publishing it, work on a separate branch and open a pull request. Only `main` deploys.

## Things to know

- **The browser version is reduced.** It uses Godot's simpler WebGL renderer: no High/Ultra effects, no grass blades (they blank the 3D view in WebGL), and no co-op (browsers can't open LAN connections). Always check a change in both the editor and the published page.
- **Co-op needs everyone on the same build.** Godot matches network messages by script, so mismatched versions disconnect.
- **`UNLOCK_ALL_ACTS`** in `game.gd` is `true` for testing; set it to `false` for a real playthrough.
- Saves live in Godot's user folder (`%APPDATA%/Godot/app_userdata/Ashen Crown` on Windows; browser storage on the web).
